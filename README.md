# جَلسة | وقت يجمعنا

«جلسة» نموذج أولي عربي يساعد الأسرة على بدء وقت مشترك عبر أسئلة حوارية، وأنشطة قصيرة، ومؤقت للجلسة، ومساعد محادثة.

## صفحات المشروع

- `index.html` — الصفحة الرئيسية والتعريف السريع بالمشروع.
- `project.html` — التحدي، الفئة المستفيدة، الحل، ورحلة الاستخدام.
- `session.html` — غرفة تفاعلية للأسئلة والمؤقت.
- `impact.html` — خطة التجربة ومؤشرات الأثر والخصوصية والاستدامة.
- `assets/site.css` — التنسيق والهوية المتجاوبة RTL.
- `assets/app.js` — تفاعلات الصفحات وواجهة المحادثة.
- `api/guide.js` — نقطة API للمساعد، تعمل على Vercel وتستخدم مفتاحًا مخزنًا في إعدادات البيئة.
- `Jalsa_Presentation.pptx` — العرض التقديمي للمشروع.

## المساعد

تفتح دائرة «ج» المحادثة من أي صفحة. يستطيع المساعد الإجابة عن أسئلة وطلبات متنوعة، مع تركيز خاص على تنظيم الوقت العائلي واقتراح أنشطة وأسئلة للحوار. يعتمد الرد على نموذج لغوي عبر OpenAI API؛ لذلك فهو ليس خدمة بشرية، وقد تخطئ إجاباته. إذا سُئل عن طبيعته، يوضح أنه مساعد رقمي.

لا يحتاج الموقع إلى حساب، ولا يحفظ سجل المحادثة في تخزين دائم بالمتصفح. تُرسل الرسالة وآخر أجزاء من سياق المحادثة إلى واجهة المشروع على Vercel ثم إلى مزود النموذج لتكوين الرد. تجنبوا إدخال الأسماء وأرقام الاتصال والمعلومات العائلية أو الحساسة. يرسل الخادم الطلب مع `store: false`، لكن ذلك لا يغني عن مراجعة شروط الخدمة وإعدادات الاحتفاظ لدى المزود قبل تجربة المشروع مع مشاركين حقيقيين.

## تشغيل الموقع

يمكن فتح ملفات HTML مباشرة لمعاينة الصفحات والتصميم والأسئلة والمؤقت. لن تعمل المحادثة عند فتح الموقع عبر `file://`؛ فهي تحتاج إلى خادم يشغّل مسار `api/guide.js`.

للتجربة محليًا باستخدام Vercel CLI:

1. ثبّتوا Vercel CLI وسجّلوا الدخول.
2. أضيفوا `OPENAI_API_KEY` كمتغير بيئة محلي باستخدام `vercel env add OPENAI_API_KEY` أو أعدّوا ملف `.env.local` محليًا. لا ترفعوا هذا الملف إلى GitHub.
3. شغّلوا `npm run dev` وافتحوا العنوان المحلي الذي يظهر.

## النشر على Vercel

1. ارفعوا محتويات هذا المجلد إلى مستودع GitHub واربطوا المستودع بمشروع Vercel.
2. في إعدادات Vercel، أضيفوا `OPENAI_API_KEY` في **Settings → Environment Variables**، واختاروا البيئات المطلوبة.
3. أعيدوا نشر المشروع بعد إضافة المتغير أو تغيير الملفات.
4. بعد النشر افتحوا رابط الموقع. عند استمرار ظهور النسخة السابقة، نفّذوا تحديثًا كاملًا للصفحة أو افتحوها في نافذة خاصة.

يمكن تحديد اسم النموذج عبر `OPENAI_MODEL` إذا لزم؛ وإلا يستخدم الخادم القيمة الافتراضية المحددة في `api/guide.js`. لا تضعوا مفتاح API في ملفات HTML أو JavaScript ولا تشاركوه. ملف `.env.example` للتوضيح فقط، وملفات `.env` مستثناة عبر `.gitignore`.

## تحديث المحادثة وذاكرة المتصفح

أضيف رقم إصدار إلى رابط `assets/app.js` في صفحات HTML حتى لا يستمر المتصفح في استخدام نسخة قديمة من النصوص. عند تحديث الملف مستقبلًا، غيّروا قيمة `v` في روابط السكربت لتجديد النسخة المخزنة مؤقتًا. إذا بقي النص القديم بعد النشر، تأكدوا من رفع ملفات HTML الأربعة و`assets/app.js` معًا إلى الفرع الذي يتتبعه Vercel، ثم انتظروا نجاح آخر عملية نشر وأعيدوا تحميل الصفحة بالكامل.

الموقع والعرض يقدّمان نموذجًا أوليًا وخطة اختبار مقترحة؛ لا توجد نتائج ميدانية مدعاة. أي قياس للأثر يحتاج إلى تجربة فعلية وموافقة المشاركين.

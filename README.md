# جَلسة | وقت يجمعنا

نموذج أولي عربي لمشروع يساعد الأسرة على بدء وقت مشترك بطريقة بسيطة.

## محتويات الموقع

- `index.html` — الصفحة الرئيسية.
- `project.html` — فكرة المشروع، المشكلة والفئة المستهدفة.
- `session.html` — غرفة جلسة تفاعلية فيها أسئلة ومؤقت.
- `impact.html` — خطة التجربة وقياس الأثر والخصوصية والتوسع.
- `assets/site.css` — الهوية البصرية والتنسيق المتجاوب المشترك.
- `assets/app.js` — تفاعلات الموقع ومساعد جلسة العائم.
- `api/guide.js` — واجهة آمنة للمساعد الذكي تعمل على Vercel.
- `Jalsa_Presentation.pptx` — العرض التقديمي للمشروع.

كل صفحة مستقلة، ويمكن التنقل بينها من القائمة. تظهر دائرة «ج» الثابتة أسفل يمين الشاشة في الصفحات كلها؛ اضغطوا عليها لفتح المحادثة. يحتفظ المتصفح بسياق المحادثة مؤقتًا خلال فتح الصفحة فقط.

## فتح الموقع

يمكن فتح `index.html` مباشرة لمعاينة التصميم والتنقل والمؤقت والأسئلة محليًا. تشغيل المساعد الذكي يحتاج استضافة تشغّل واجهة `api/guide.js`؛ فتح الملفات مباشرة عبر `file://` لا يشغّل هذه الواجهة.

للتجربة المحلية مع Vercel CLI:

1. ثبّتوا Vercel CLI وسجّلوا الدخول.
2. أضيفوا `OPENAI_API_KEY` إلى إعدادات المشروع المحلية عبر `vercel env add OPENAI_API_KEY`، أو من لوحة Vercel.
3. شغّلوا `npm run dev` وافتحوا العنوان المحلي الذي يظهر.

## النشر على Vercel

ارفعوا مجلد المشروع إلى مستودع GitHub، ثم اربطوه بمشروع Vercel. أضيفوا `OPENAI_API_KEY` في إعدادات المشروع تحت **Environment Variables**، ثم أعيدوا النشر. يمكن تحديد اسم النموذج بمتغير `OPENAI_MODEL`؛ الافتراضي مضبوط في `api/guide.js` ويمكن تغييره إلى نموذج متاح لحسابكم.

لا تضعوا مفتاح الخدمة داخل HTML أو JavaScript ولا ترفعوه إلى Git. ملف `.env.example` للتوضيح فقط، وملفات `.env` مستثناة في `.gitignore`.

## الخصوصية وحدود النموذج

لا يحتاج الموقع إلى إنشاء حساب، ولا يحفظ سجل المحادثة في التخزين الدائم للمتصفح. عند إرسال رسالة للمساعد، تُرسل الرسالة والسياق القصير إلى واجهة المشروع على Vercel ثم إلى مزود النموذج لتكوين رد. لا تكتبوا أسماء أو أرقام اتصال أو معلومات عائلية خاصة. الطلب إلى مزود النموذج مضبوط على `store: false`؛ راجعوا شروط الخدمة وإعدادات الاحتفاظ لدى المزود قبل تجربة المشروع مع مشاركين حقيقيين.

الموقع والعرض يقدّمان نموذجًا أوليًا وخطة اختبار مقترحة. لا توجد نتائج ميدانية مدعاة؛ أي قياس للأثر يحتاج تجربة فعلية وموافقة المشاركين.

# جَلسة | وقت يجمعنا

«جلسة» نموذج أولي عربي يساعد الأسرة على بدء وقت مشترك عبر أسئلة حوارية، وأنشطة قصيرة، ومؤقت للجلسة، وخيارين بردود جاهزة.

## صفحات المشروع

- `index.html` — الصفحة الرئيسية والتعريف السريع بالمشروع.
- `project.html` — التحدي، الفئة المستفيدة، الحل، ورحلة الاستخدام.
- `session.html` — غرفة تفاعلية للأسئلة والمؤقت.
- `impact.html` — خطة التجربة ومؤشرات الأثر والخصوصية والاستدامة.
- `assets/site.css` — التنسيق والهوية المتجاوبة RTL.
- `assets/app.js` — تفاعلات الصفحات وردود المساعد الجاهزة.
- `Jalsa_Presentation.pptx` — العرض التقديمي للمشروع.

## المساعد

اضغطوا دائرة «ج» لفتح المساعد، ثم اختاروا أحد الخيارين:

1. خطة ربع ساعة بعد العشاء.
2. نشاط يشارك فيه الصغار والكبار.

يعرض الموقع الرد المحفوظ فورًا. المساعد محدود بهذين الخيارين ولا يستقبل أسئلة حرة. تعمل الردود داخل المتصفح ولا تتصل بأي خدمة خارجية، ولا تحتاج إلى مفتاح أو إعداد إضافي.

## تشغيل الموقع

يمكن فتح `index.html` مباشرة لمعاينة الصفحات والتصميم والأسئلة والمؤقت والمساعد. كما يمكن رفع محتويات المجلد إلى Vercel أو أي استضافة صفحات ثابتة؛ لا يحتاج الموقع إلى خادم API.

للتجربة المحلية عبر Vercel CLI، شغّلوا `npm run dev` بعد تثبيت CLI وتسجيل الدخول.

## النشر والتحديث

ارفعوا ملفات المشروع إلى مستودع GitHub المرتبط بمشروع Vercel. بعد اكتمال النشر، افتحوا الموقع وحدّثوا الصفحة تحديثًا كاملًا إذا ظهرت نسخة قديمة. عند تغيير `assets/app.js` مستقبلًا، حدّثوا رقم `v` في روابط السكربت داخل صفحات HTML الأربع حتى لا يعيد المتصفح استخدام نسخة مخزنة قديمة.

الموقع والعرض يقدّمان نموذجًا أوليًا وخطة اختبار مقترحة؛ لا توجد نتائج ميدانية مدعاة. أي قياس للأثر يحتاج إلى تجربة فعلية وموافقة المشاركين.
